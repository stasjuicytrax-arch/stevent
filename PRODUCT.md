# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Чистый HTML + CSS + JavaScript, без React и сборщиков. Анимации — GSAP +
ScrollTrigger, файлы лежат локально в `assets/vendor/` (не с CDN). Один
`index.html`, `css/` и `js/` разбиты по секциям. Зафиксировано в `CLAUDE.md`
и `docs/03-TZ.md`, раздел 2.

## Users

Первично — HR- и маркетинг-директора крупных компаний Перми и региона.
Вторично — частные заказчики (свадьбы, дни рождения).
(docs/03-TZ.md, раздел 1)

## Product Purpose

Лендинг ST EVENT заменяет многостраничный сайт агентства на Tilda: переносит
контент восьми кейсов портфолио, страниц «О нас» и «Контакты» на одну
страницу. Цель страницы — заявка на расчёт мероприятия (звонок или форма).
(docs/03-TZ.md, раздел 1)

## Positioning

Event-агентство в Перми с 2008 года, работающее и с крупным корпоративным
заказчиком (СИБУР, ВТБ — требует серьёзности), и с яркими частными проектами
(Ibiza Party, Битва роботов — требует энергии). Позиционирование держится на
сочетании этих двух регистров, а не на выборе одного.
(docs/02-DESIGN-SYSTEM.md, раздел 1)

## Brand Commitments

Название ST EVENT (кириллица — СТ-СОБЫТИЯ), дескриптор
«событие // искусство // видео», год основания 2008, город Пермь.
Тон — «технологичный минимализм с горячим нервом»: холодная чёрная база +
один горячий акцент, который появляется только в момент действия (кнопка,
номер, ховер, цифра). Три слова: строго · крупно · горячо.
(docs/01-CONTENT.md §1; docs/02-DESIGN-SYSTEM.md §1)

## Evidence on Hand

Все тексты и цифры — только из `docs/01-CONTENT.md`, все изображения —
только из `assets/`. На старом сайте нет и не выдумываются: персональных
био команды, текстовых отзывов клиентов, страницы цен, юридических данных
(docs/01-CONTENT.md §8) — эти блоки в первой версии отсутствуют.

## Product Principles

- Тексты и цифры — только из `docs/01-CONTENT.md`, ничего не «улучшать» и не
  дописывать от себя.
- Один горячий акцент на экран, не больше 5% площади — если больше, это уже
  не акцент.
- Серьёзность для корпоративного заказчика и энергия частных проектов не
  разбавляют друг друга — оба регистра держатся раздельно по секциям.
