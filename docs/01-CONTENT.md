## 8. Чего на старом сайте нет — запросить у клиента

Эти блоки нельзя придумывать, их нужно получить:

1. **Биография / команда.** Персональных био на сайте нет. Упоминалось фото
   команды (`assets/common/about-team.jpg`), но при визуальной проверке файла
   (ревизия, вечер 23.09.2026) выяснилось, что это не фото команды ST EVENT,
   а фото фасада стороннего объекта «PLAYPARK» — по аналогии с client-13/
   client-14 (см. §5), актив подписан неверно. Использовать нельзя, в блоке
   «О нас» оставлен TODO вместо фото.
   → Нужны: имя основателя, должность, 2–3 абзаца истории агентства, фото
   команды (реальное, не текущий файл).
2. **Отзывы клиентов.** Есть только упоминание видеоотзыва без самого видео.
   → Нужны 3–5 текстовых отзывов с именем, должностью, компанией.
3. **Цены.** В футере есть пункт «ЦЕНЫ», но страницы нет.
   → Нужно: либо вилки бюджетов, либо убрать пункт.
4. **Юридические данные.** ИНН, ОГРН, полное название юрлица — для футера и
   политики конфиденциальности (обязательна по 152-ФЗ, раз есть форма).
5. **Названия 7 неопознанных клиентов** (см. раздел 5).
6. **Список городов** для карты географии (см. раздел 6).
7. **Видео.** В дескрипторе заявлено «видео», но видеоматериалов на сайте нет.
   → Если есть шоурил — он украсит hero.
