## R18. Hero-экран — всё по центру

Сейчас логотип в шапке слишком мелкий, заголовок ST EVENT сбит влево.

1. Логотип в шапке увеличить — минимум 40px по высоте (см. R1 из
   `04-REVISION-01.md`), сейчас явно меньше.
2. Весь контент hero-острова (дескриптор, ST EVENT, подзаголовок, кнопка
   «ОБСУДИТЬ ПРОЕКТ») выровнять по центру острова: `text-align: center`,
   flex-контейнер с `align-items: center`.
3. Меню (капсулу) в шапке не трогать — оставить как есть.
4. Убрать номер телефона из правого блока шапки. R17 из
   `05-REVISION-02.md` предполагал телефон на первом экране — эта часть
   отменяется, правый блок на первом экране пустой. Сетка
   `grid-template-columns: 1fr auto 1fr` для центрирования капсулы меню
   сохраняется.

## R19. Аккордеон услуг — раскрывается только первая карточка

Баг: карточки №2, №3, №4 не реагируют на клик. Найти обработчик клика в
JS, проверить, что слушатель повешен на каждый `.accordion__item`, а не
только на первый, и что логика «открыта всегда ровно одна»
(`03-TZ.md`, секция 03) не блокирует остальные из-за неверной привязки
индекса/id.
