## 2. Палитра (утверждена заказчиком 26.10.2026)

```css
:root {
  /* база — чёрный в четыре ступени */
  --c-void:      #0A0A0A;  /* фон страницы */
  --c-graphite:  #141414;  /* фон секций-«островов» */
  --c-carbon:    #1F1F1F;  /* карточки, поля формы */
  --c-steel:     #2E2E2E;  /* линии, ховер карточек, разделители */

  /* акцент */
  --c-lime:       #D4FF2A; /* главный: CTA, ленты, цифры, целые блоки */
  --c-lime-press: #B8E600; /* ховер/нажатие лаймовой кнопки */

  /* светлый */
  --c-bone:      #F2F1EA;  /* основной текст и редкие светлые секции */

  /* производные */
  --c-text:       var(--c-bone);
  --c-text-dim:   rgb(242 241 234 / .58);
  --c-text-faint: rgb(242 241 234 / .32);
  --c-line:       rgb(242 241 234 / .10);
  --c-on-lime:    var(--c-void);       /* текст на лайме — только чёрный */
  --lime-glow:    rgb(212 255 42 / .35); /* свечение за объектом на фото */
}
```

**Отклонено:** тёмно-оливковый `#2A3300` («lime shadow») — не используем
нигде. Никаких болотных/оливковых промежуточных оттенков лайма.

### Правила цвета
- Лайм используется **щедро**, но осмысленно: целые полосы и блоки (бегущая
  строка, финальный CTA, активная плашка), главная кнопка, цифры, стрелки,
  курсор, активный фильтр. На одном экране — максимум **один** крупный
  лаймовый блок.
- Текст на лайме — только `--c-void`. Лаймовый текст на чёрном — только
  крупный (цифры, акцентное слово в заголовке), не для абзацев.
- Светлый `--c-bone` как **фон** — максимум 1–2 секции на весь сайт
  (например, «О нас» под рваным краем). Это «передышка», не система.
- Никаких градиентов «лайм → что-то». Свечение (`--lime-glow`, размытый круг
  за объектом) — да, градиентные заливки — нет.

## 3. Типографика

Кириллица обязательна.

```css
--font-display: 'Unbounded', system-ui, sans-serif; /* 800–900, ВЕРХНИЙ РЕГИСТР */
--font-text:    'Onest', system-ui, sans-serif;     /* 400–600 */
--font-mono:    'JetBrains Mono', ui-monospace, monospace; /* 400–500, подписи */
```

- Шрифты локально в `assets/fonts/`. Проверить, что в текущих woff2 Unbounded
  есть веса 800–900 (если файл не вариативный — докачать нужные веса с
  кириллицей). JetBrains Mono — скачать кириллический + латинский сабсет.
- **Заголовки — тяжёлые и огромные**: hero до `clamp(56px, 11vw, 200px)`,
  межстрочный 0.9, трекинг −0.02em. Это главный визуальный приём — типографика
  работает как картинка.
- Моно — для служебных подписей: номера секций `[01]`, мета кейсов
  («Крон · юбилей компании · 140 человек»), подписи под цифрами. Размер
  11–13px, трекинг +0.04em, ВЕРХНИЙ РЕГИСТР.
- Правило из старой системы сохраняется: крупным кеглем — только фразы до
  7 слов. Абзацы — `--font-text` 16–18px.

## 4. Форма и поверхности

- Радиусы: карточки и острова 24–32px, кнопки и пилюли — полностью круглые
  (999px), фото в бенто — 20px.
- Секции-«острова»: блок с отступом 12–16px от краёв экрана и большим
  радиусом (как лаймовый hero и CTA у Das Grüne).
- Рваный край (SVG-маска, 2–3 разных формы) — на 1–2 стыках секций, не
  везде.
- Звёздочка ✦ и крестик + — графические маркеры-разделители (в лентах,
  полосе преимуществ).
- Зерно: `assets/brand/texture-noise.gif` поверх всего сайта, opacity 0.04–0.06,
  `pointer-events: none`.

### Жидкое стекло (Liquid Glass)
Исходник: `references/liquid-glass/apple-tahoe-liquid-glass-button.source.txt`
(React + TS, MIT, автор HJHossain Jahed). Сайт на чистом JS — **портировать
в `js/liquid-glass.js`** (IIFE, без React, без сборки): генерация карт
смещения на canvas → SVG `<filter>` с `feDisplacementMap` → `backdrop-filter:
url(#…)`. В Chromium — преломление, в Safari/Firefox — фолбэк «матовое
стекло» (`backdrop-filter: blur() saturate()`). Пружинная физика нажатия и
подсветка под курсором — для кнопок.

Применяем к: плашке меню в шапке (капсула со ссылками), второстепенным
кнопкам («Посмотреть проекты»), пилюлям-фильтрам портфолио, двум плашкам
«Корпоративный / Частный клиент», кнопке закрытия модалки кейса, стеклянной
карточке в углу hero. **Главная кнопка «Обсудить мероприятие» — сплошной
лайм, не стекло.** Стекло лучше всего смотрится поверх фото — ставим его там,
где под ним есть картинка.

## 5. Обработка фото

- Базово — **Ч/Б, высокий контраст** (`filter: grayscale(1) contrast(1.15)`).
- В hero и на обложках ключевых кейсов — **лаймовое свечение за объектом**
  (размытый круг `--lime-glow`, как в NEXUS).
- На ховер карточки кейса — переход в цвет или лаймовый дуотон (тени
  `--c-void`, света `--c-lime`) через SVG-фильтр `feColorMatrix`.
- Моушн-шлейф (приём addco/kozyuk): у фото героя — 3–4 копии изображения со
  смещением и уменьшающейся прозрачностью, реагируют на скорость скролла/мыши.

## 6. Вау-механики — список по секциям

Стек тот же: GSAP + ScrollTrigger + Lenis локально. Можно добавить
`SplitText` и `Flip` из GSAP (с 2025 все плагины GSAP бесплатные) — скачать
в `assets/vendor/`. Всё отключается при `prefers-reduced-motion`.

**Порядок и состав блоков — как в текущем `index.html`, не меняем.**
Меняем только дизайн и движение. Разметку, тексты, id секций, данные кейсов,
форму, карту и логику модалок переиспользуем, CSS и анимации пишем заново.

Текущий порядок: шапка → `#hero` → `#about` (манифест/основатели) →
`#services` → `#why-us` → `#portfolio` → `#fan-gallery` → `#clients` →
`#geography` → `#contacts` → футер.

| Секция | Механика |
|---|---|
| Прелоадер | Счётчик годов `2008 → 2026` моно-шрифтом, затем лаймовая шторка уходит вверх и открывает hero; заголовок hero собирается из букв (SplitText, буквы выезжают из-под маски снизу со stagger). |
| Шапка | Стеклянная капсула-меню, лаймовая кнопка справа. Прячется при скролле вниз, возвращается при скролле вверх. Активный пункт подсвечен «стеклянной каплей», которая перетекает между пунктами (Flip). |
| Курсор (весь сайт) | Кастомный: лаймовая точка 10px, `mix-blend-mode: difference`; над карточками кейсов вырастает в круг 90px с текстом «СМОТРЕТЬ»; над кнопками — магнитный эффект. Только на устройствах с мышью. |
| `#hero` | Огромный заголовок, фото с лаймовым свечением и моушн-шлейфом, фото слегка следует за мышью (параллакс 10–20px). На фоне — гигантская контурная надпись `ST EVENT` (stroke без заливки), едет при скролле. Две стеклянные плашки «Корпоративный / Частный клиент». Стеклянная мини-карточка в углу. Сразу под hero — **лаймовая бегущая лента** `ОБСУДИТЬ МЕРОПРИЯТИЕ ✦ …`: скорость и skew зависят от скорости скролла, при скролле вверх едет обратно; вторая чёрная лента под углом перекрещивается с ней. |
| `#about` | Фраза-манифест — **текст с картинками-пилюлями внутри строки** (маленькие закруглённые фото с мероприятий между словами), слова заливаются цветом по мере скролла (scrub). Фото основателей Ч/Б «проявляются» шторкой. |
| `#services` | Три направления — строки во всю ширину. На ховер: строка подсвечивается, справа выезжает лаймовый квадрат со стрелкой, **за курсором летит картинка** из подходящего кейса. Клик — раскрывается список (аккордеон по ТЗ). |
| `#why-us` | Единственная светлая секция (`--c-bone`) с **рваным краем** сверху и снизу. Карточки преимуществ **лежат стопкой вразброс** под углами; при скролле разлетаются и выстраиваются в ряд. Цифры докручиваются счётчиком. За карточками — огромный полупрозрачный заголовок. |
| `#portfolio` | Стеклянные пилюли-фильтры; при смене карточки перестраиваются анимацией Flip. **Бенто-сетка** разных размеров. Ховер: Ч/Б → цвет, зум 1.05, лаймовая круглая стрелка, мета моно-шрифтом. Клик → модалка, обложка раскрывается из карточки (Flip), в конце — лаймовый CTA-блок по ТЗ. |
| `#fan-gallery` | Сохранить идею веера, но усилить: карточки раскрываются веером от скролла с вращением и глубиной, активная — в цвете, остальные Ч/Б. |
| `#clients` | Две ленты логотипов навстречу друг другу, монохром → на ховер белые. |
| `#geography` | Карта в стилистике: чёрная, контуры тонкой линией, точки городов лаймовые, загораются по очереди при появлении секции. Названия городов — крупным контурным шрифтом, на ховер заливаются лаймом. |
| `#contacts` | **Лаймовый остров** во весь экран с огромным заголовком, чёрные кнопки, форма — на чёрной карточке внутри. |
| Футер | **Гигантское `ST EVENT` на всю ширину**, буквы выезжают снизу по одной при доскролле. Над ним — ссылки, контакты, соцсети моно-шрифтом. |

### Общие правила движения
- Плавный скролл Lenis, все анимации привязаны к нему.
- Easing по умолчанию — `expo.out` / `power4.out`, длительности 0.8–1.4s.
  Никаких линейных фейдов «снизу вверх на 20px» как единственного приёма.
- Каждая секция — **свой** приём. Повторять один и тот же reveal во всех
  секциях запрещено — именно это сделало прошлую версию скучной.
- Производительность: анимировать только `transform` и `opacity`, `will-change`
  снимать после анимации. 60 fps на среднем ноутбуке.
- Мобильный: курсор, следующие за мышью картинки и параллакс отключаются;
  ленты, счётчики, разлёт карточек, Flip — остаются.
