## R10. Меню — стеклянная капсула

Нужен эффект матового стекла: полупрозрачная капсула, сквозь которую
видно размытый контент под ней.

```css
.nav-capsule {
  border-radius: var(--r-full);
  padding: 8px 10px;
  background: rgba(255,255,255,.07);
  backdrop-filter: blur(24px) saturate(180%);
  -webkit-backdrop-filter: blur(24px) saturate(180%);
  border: 1px solid rgba(255,255,255,.12);
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.18),   /* верхний блик */
    inset 0 -1px 0 rgba(0,0,0,.25),        /* нижняя тень */
    0 8px 32px rgba(0,0,0,.35);            /* отрыв от фона */
}
```

**Пункты меню** лежат внутри капсулы. Активный и наведённый получают
свою подкапсулу: `background: rgba(255,255,255,.10)`, `--r-full`,
которая **переезжает** между пунктами за `--dur` с `--ease` — не
появляется заново, а скользит. Реализовать одним абсолютным элементом,
позиция которого считается от ширины пункта.

**При скролле** капсула уплотняется: `padding` уменьшается до `6px 8px`,
`background` до `rgba(255,255,255,.10)`, blur до `32px`.

**Важно:** это единственное место на сайте со стеклом. Стеклянные
карточки, стеклянные модалки и прочий glassmorphism запрещены —
приём работает, только пока он один.

Фолбэк для браузеров без `backdrop-filter`:
`@supports not (backdrop-filter: blur(1px))` → сплошной
`rgba(8,8,10,.88)`.

## R12. Тонкие линии — фирменный приём сайта

Индексная строка под hero (`#01 СОБЫТИЯ · #02 БТЛ · …`, разделённая
вертикальными линиями) работает хорошо. Заказчику нравится.

**Сделать это сквозным приёмом.** Волосяная линия
`1px solid var(--line)` становится основным способом членения:

- горизонтальная линия над каждым маркером секции, во всю ширину контейнера;
- вертикальные разделители между колонками в многоколоночных блоках
  (счётчики манифеста, «Почему мы», футер);
- линия между строками аккордеона услуг — уже есть, оставить;
- в контактах линия разделяет колонку контактов и колонку формы.

**Оживить линии.** При появлении секции горизонтальная линия
прочерчивается слева направо: `scaleX(0) → 1`,
`transform-origin: left`, `--dur-slow`, `--ease`. Это дешёвый по
исполнению и очень заметный эффект.

## R15. География — точечная карта России с 3D-наклоном

Секция остаётся. Делается эффектной, но **без выдуманных городов**.

### Почему не случайные точки

Точка на карте читается как «мы здесь работали». Поставить их наугад —
значит написать на сайте агентства неправду, которую клиент увидит
первым. Если он потом покажет сайт заказчику из города, где ST Event
никогда не был, это ударит по нему, а не по нам.

Плотность и «вау» дадим графикой, а не фальшивыми пинами.

### Как строится

**Основа — dot-matrix.** Вся территория России набрана точечной сеткой:
тысячи мелких кружков диаметром 2–3px с шагом 8px, залитые только там,
где есть суша. Контур не рисуется линией — он проявляется сам, из
плотности точек. Это даёт масштаб и богатую фактуру безо всякого
содержания.

Как сделать:
1. Скачать упрощённый GeoJSON границ России (Natural Earth, admin 0,
   разрешение 1:110m) в `assets/data/`.
2. Спроецировать в Albers Equal Area Conic — стандартная проекция для
   России, широта стандартных параллелей 52° и 64°, центральный
   меридиан 100°E. Меркатор не годится: раздувает Север до абсурда.
3. Растеризовать в offscreen-canvas, пройти сеткой 8px, для каждого
   узла проверить попадание в полигон. Попал — точка.
4. Отрисовать в основной canvas или в SVG.

**3D-наклон.** Контейнер карты получает
`transform: perspective(1400px) rotateX(52deg) rotateZ(-8deg)`.
Карта ложится в плоскость, как стол. Под ней — мягкая тень-градиент.

**Реакция на курсор.** `rotateX` и `rotateZ` меняются в пределах ±4°
вслед за положением мыши, с задержкой 300ms. Слабо, дорого, не
укачивает. На тач-устройствах отключается.

**Появление.** При входе секции точки проявляются волной от центра
к краям: `opacity 0 → 1` + `scale(.4) → 1`, задержка каждой точки
пропорциональна расстоянию от центра, общая длительность 1.2s.
Волна проходит **один раз**. Зацикленной пульсации нет — это запрещено
дизайн-системой, раздел 8.

**Реальные города.** Только те, что подтверждены кейсами:
**Пермь** (7 проектов) и **Сочи** (1 проект). Каждый — вертикальный
столбик, вырастающий из плоскости карты вверх на 40px, цвет `--accent`,
сверху точка и подпись с названием и числом проектов. Подпись не
наклонена вместе с картой, стоит вертикально к зрителю.

**Слева от карты** — крупно, типографикой: `2 ГОРОДА`, `8 ПРОЕКТОВ`,
`С 2008 ГОДА`. Это заполняет блок настоящими цифрами.

### Производительность

Точек будет несколько тысяч. Рисовать их DOM-элементами нельзя —
только canvas. Перерисовка на наклон — через `transform` контейнера,
а не перерисовкой canvas. Для retina учесть `devicePixelRatio`.

### Когда клиент пришлёт список городов

Добавить остальные пины и обновить цифру `2 ГОРОДА`. Структура уже
будет готова — меняется только массив городов в `assets/data/`.

## R16. Мало движения — усилить

Текущий набор анимаций слишком осторожен, сайт читается как статичный
макет. Раздел 8 дизайн-системы расширен, см. его же.

**Добавить, в порядке важности:**

1. **Инерционный скролл (Lenis).** Даёт основную долю ощущения
   «дорогого» сайта. `duration: 1.1`, `easing`
   `t => Math.min(1, 1.001 - Math.pow(2, -10*t))`. Подключить локально
   в `assets/vendor/`. Обязательно связать со `ScrollTrigger.update`.

2. **Hero-заголовок по буквам.** `ST EVENT` собирается из букв:
   каждая выезжает снизу из-под маски, `stagger: 0.04`, `--dur-slow`.
   Не по словам — по буквам, буква крупная, эффект читается.

3. **Уход hero при скролле.** Пока пролистывается первый экран,
   остров уменьшается до `scale(.94)`, теряет непрозрачность до `.5`
   и слегка размывается `blur(4px)`. Привязать к `ScrollTrigger`
   со `scrub: true`.

4. **Смена темы по скроллу.** Фон `body` плавно переходит
   `--bg → --bg-light` при входе в светлую секцию и обратно при выходе.
   Не резкая граница, а интерполяция по `scrub`. Цвет текста меняется
   вместе с фоном.

5. **Прочерчивание линий** — см. R12.

6. **Счётчики-одометр.** Цифры не просто докручиваются, а
   прокручиваются вертикально, как в механическом счётчике: колонка
   цифр 0–9 едет вверх и останавливается на нужной. `--dur-slow`.

7. **Маска на раскрытие секций.** Каждая секция входит через
   `clip-path: inset(0 0 100% 0) → inset(0 0 0% 0)`, `--dur-slow`.

8. **Магнитные пункты меню.** Не только кнопка — пункты навигации тоже
   слегка притягиваются к курсору, радиус 24px, смещение до 4px.

9. **Модалка кейса** открывается не fade-ом: карточка визуально
   разворачивается в полноэкранный вид через FLIP
   (`gsap.flip` или ручной расчёт `getBoundingClientRect`).

**Что по-прежнему запрещено:** pulse, glow, breathing, автоплей-слайдеры,
параллакс быстрее 10%, анимации дольше 1.2s, вылеты с четырёх сторон,
эффекты ради эффектов на второстепенных элементах.

**Обязательно:** `prefers-reduced-motion` выключает всё до мгновенных
переходов, включая Lenis.
