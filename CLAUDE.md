# Проект ST EVENT — правила для агента

Лендинг для event-агентства ST EVENT (Пермь, с 2008 года).
Замена старого многостраничного сайта на Tilda.

## Перед любой задачей прочитай

1. `docs/01-CONTENT.md` — весь контент. Источник правды по текстам и цифрам.
2. `docs/02-DESIGN-SYSTEM.md` — палитра, типографика, сетка, движение, антислоп.
3. `docs/03-TZ.md` — структура лендинга и порядок сборки.
4. `docs/04-REVISION-01.md` — ревизия №1 по скриншотам.
5. `docs/05-REVISION-02.md` — ревизия №2. **Самый высокий приоритет.**
   Где документы расходятся, действует более поздняя ревизия.
6. `references/4.jpg` и `references/18.jpg` — визуальные референсы.

## Жёсткие правила

- **Тексты только из `docs/01-CONTENT.md`.** Ничего не выдумывать, не
  «улучшать», не дописывать. Нет данных — оставить TODO и сказать об этом.
- **Цифры только из `docs/01-CONTENT.md`.** Никаких «500+ проектов» из головы.
- **Изображения только из `assets/`.** Ни одной внешней ссылки, ни одного
  `tildacdn.com`, ни одного placeholder-сервиса, ни одного Unsplash.
- **Стек:** чистый HTML + CSS + JS. Без React, без сборщиков. GSAP лежит
  локально в `assets/vendor/`.
- **Токены:** все цвета, размеры и отступы — через CSS-переменные из
  `css/tokens.css`. Хардкод значений в компонентах запрещён.
- **Одна задача — один шаг.** Не генерировать весь сайт разом.

## Стиль кода

- Семантический HTML, БЭМ-подобные классы (`case-card__title`).
- CSS: без `!important`, без `box-shadow` на карточках, без вложенности глубже 3.
- JS: классические `<script defer>`, **без `type="module"`** — сайт должен
  работать по `file://`, а ES-модули там блокируются CORS. Изоляция через
  IIFE. Без jQuery, `addEventListener`, чистые функции.
- Комментарии — на русском, коротко, только там где неочевидно.

## Перед завершением любой секции

Прогнать антислоп-чеклист из `docs/02-DESIGN-SYSTEM.md`, раздел 9.
