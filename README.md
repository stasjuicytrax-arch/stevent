# ST EVENT — лендинг

Одностраничный сайт event-агентства ST EVENT (Пермь, с 2008 года). Заменяет
старый многостраничный сайт на Tilda: портфолио кейсов, услуги, география
проектов, контакты и форма заявки — на одной странице.

## Стек

Чистые HTML + CSS + JavaScript, без React и без сборщиков. Анимации — GSAP +
ScrollTrigger + Lenis, подключены локально из `assets/vendor/` (без CDN).
Сайт открывается напрямую по `index.html`, в том числе двойным кликом с
диска (`file://`), без сборки и без сервера.

## Структура

```
index.html          главная страница
privacy.html         страница политики конфиденциальности
css/                 стили по файлам (tokens, reset, base, components, sections)
js/                  скрипты по функциональности, каждый — независимый IIFE
assets/              изображения, шрифты, векторные иконки, локальные вендор-библиотеки
docs/                контент, дизайн-система, техзадание и история ревизий
```

## Запуск

Открыть `index.html` в браузере — либо двойным кликом, либо через любой
статический сервер (`npx serve`, `python -m http.server` и т.п.).

## Деплой

Сайт статический — подходит для GitHub Pages без дополнительной настройки:
`index.html` лежит в корне репозитория, все пути к файлам относительные.
